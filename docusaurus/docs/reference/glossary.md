# Glossário

| Termo | Significado |
| --- | --- |
| Instrumento B3 | Unidade financeira na raiz cadastral B3, contextualizada por identificadores e histórico |
| Ticker | Código publicado em um mercado e período; pode mudar ou ser reutilizado |
| Security ID | Código de instrumento qualificado pelo namespace da fonte |
| Fotografia | Observação cadastral ligada à publicação e data de referência |
| Janela de validade | Intervalo sustentado por evidência de associação do identificador |
| Fato de mercado | Registro de negociação publicado, com data, mercado, unidade e proveniência |
| DISMES | Número de distribuição do papel, parte da granularidade de COTAHIST |
| PREULT | Último negócio publicado no registro COTAHIST |
| FATCOT | Fator de cotação do arquivo, sem equivalência a ajuste corporativo |
| Revisão | Conjunto explícito de registros em construção ou publicação |
| Snapshot | Fotografia/versionamento de observações cadastrais publicadas |
| Member | Entrada dentro de artefato ou container inventariada com índice e origem |
| Proveniência | Localizadores que conectam item consultado ao arquivo e registro original |
| Quarentena | Registro rejeitado preservado com razão e localização para recuperação |
| Elegibilidade | Evidência de permissão/custo por fonte, canal e finalidade de uso |
| Série nominal | Valores originais da época sem ajustes retroativos |

Termos completos e escolhas de vocabulário do projeto estão em [docs/domain/CONTEXT.md](https://github.com/JoseLArantes/b3-tucano/blob/main/docs/domain/CONTEXT.md).
